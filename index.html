What I'm working on now

At SUTD I'm working on LLM-guided fuzzing for machine learning model files. A lot of models are shared as pickle files, and a pickle can run code the moment you load it, which makes it a nice place to hide something malicious. I've been reproducing tools like ShadowPickle, PickleFuzzer and DynaHug/DynaOrg to get baselines, and now I'm trying to use LLMs to make the fuzzer smarter about what it mutates, so it finds the deeper bugs that normal fuzzers miss.

More generally, I like AI that actually does things. Not just a chatbot that answers you, but agents that can use tools, make decisions and get work done. I'm just as interested in what goes wrong once you give models that much freedom. Fintech and fraud detection are the other rabbit hole I keep falling into.

FeedbackFuzz

Research prototype, 2026

Built on top of HLPFuzz (USENIX Security 2025), which uses an LLM to get a fuzzer past tricky constraints. When the LLM's attempt fails, FeedbackFuzz works out what kind of error it was (syntax, type or semantic) and gives the model feedback written for that kind of error. In my tests it needed 27.9% fewer attempts.

LLM-guided fuzzing, constraint solving, Python
